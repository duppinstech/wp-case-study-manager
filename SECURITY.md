# Security Policy

## Supported Versions

Security fixes are provided for the latest release on the default branch.

## Reporting a Vulnerability

Please report vulnerabilities privately by emailing:

- **odell@duppinstech.com**

Include:

- A clear description of the issue
- Steps to reproduce
- A proof-of-concept (if available)
- Potential impact

You can expect an initial response within **3 business days**.

## Disclosure Policy

- Please do not open public GitHub issues for security vulnerabilities.
- After triage and a fix, a coordinated disclosure may be published.

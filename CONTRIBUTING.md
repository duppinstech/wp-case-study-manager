# Contributing

## Branch naming

Branch from `main`. Name the branch `type/short-description`, for example `fix/permalink-flush` or `chore/sdlc-baseline`.

Do not commit on `main`.

## Commit style

Use [Conventional Commits](https://www.conventionalcommits.org/):

```text
type: short description
```

Common types in this repository: `feat`, `fix`, `docs`, `chore`, and `ci`.

## Pull requests

1. Open the pull request against `main`.
2. Complete `.github/PULL_REQUEST_TEMPLATE.md`.
3. Run `composer test` and `composer lint`.
